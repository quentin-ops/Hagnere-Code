## 10. Registre des incidents et contre-audit après correction

Chaque incident possède un seul identifiant. Une même cause n'est pas comptée
deux fois parce qu'elle apparaît dans plusieurs sections. Le mot `P1` qui
désigne la première passe n'est jamais compté comme une gravité.

```text
P0 ouverts :
P1 ouverts :
P2 ouverts :
REJETÉS :
```

| ID | Gravité | Preuve localisable | Conséquence lecteur | Correction exigée | Revalidation indépendante |
| -- | ------- | ------------------ | ------------------- | ------------------ | -------------------------- |
| P0-01 | P0 | | | | |
| P1-01 | P1 | | | | |
| P2-01 | P2 | | | | |

Le compteur de synthèse doit être égal au nombre d'identifiants ouverts. Une
suggestion non retenue devient `R-01`, avec le motif et la preuve qui ont
conduit au rejet.
